# NEXUS FFA

Portable Quest 3 / WebXR build of NEXUS FFA.

Open the GitHub Pages site in Meta Quest Browser and press **ENTER VR**.

Current build includes:
- Immersive WebXR entry
- Quest hand tracking foundation
- Right-hand weapon gestures: handgun / sword / sniper
- Sniper squeeze-release firing
- Left-hand pinch locomotion foundation
- Sword hit + delayed Echo Slash foundation
- Left-palm throwing knife foundation
- 7 bots with health / respawn
- NEXUS ENERGY pickups
- Moving bank
- 30-point win target
- Quest-conscious low-cost 3D city rendering

This is an independent portable rebuild based on the NEXUS FFA design spec, not an export of Floot's private source.
